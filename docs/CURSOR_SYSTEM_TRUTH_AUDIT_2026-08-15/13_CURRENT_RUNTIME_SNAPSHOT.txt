DIRECT STRUCTURAL FAILURE EVIDENCE

One inspected query asked, with spelling errors, for exact application steps as an international student while also mentioning class registration. The system routed it to student_services:explain, selected a student-success taxonomy, required housing/dining/bookstore evidence, released bookstore evidence, marked CAN_RELEASE, and logged success.

This is not merely missing data. It demonstrates a structural validation gap: a wrong interpretation can select a wrong evidence contract, satisfy that contract, and pass release.

A separate sequence showed conversation-state contamination. A Fall 2026 semester-start question produced a clarification without retrieval. The next unrelated message inherited an academic-calendar deadline task and also produced a clarification. This demonstrates that task state can survive a topic change when it should be reset.

WORKING-TREE WARNING

At inspection time the Git working tree already contained many modified backend, frontend, test, environment-example, and feature-documentation files, plus an untracked backend HTTP runtime file. Those changes predate or are outside this documentation-only pass. They must be reviewed as a coherent change set before any production claim, commit, or rollback.

PRIVACY AND OPERATIONS WARNING

Question-text logging and verbose debug traces are useful locally but can collect student language and sensitive context. Production logging should minimize raw text, redact identifiers, define retention, restrict access, and use structured reason codes. Development-only reset behavior and insecure cookies must not be carried into an HTTPS production deployment.

CURRENT HONEST PRODUCT STATEMENT

The local system is running and has strong infrastructure for source-governed answers, selected deterministic campus workflows, guest usage, and schedule planning. Its correctness is uneven outside well-covered flows. The immediate trust issue is semantic: route selection, conversation state, and evidence relevance can disagree while the pipeline still records success.
