# Social media / communications workflow

```text
DRAFT
  → INTERNAL_REVIEW
  → APPROVED
  → SCHEDULED
  → PUBLISHED
  → ARCHIVED
```

## Post fields

- Platform
- Campaign
- Related event or project
- Draft copy / media
- Accessibility text
- Reviewer / approver
- Scheduled time
- Published link
- Performance metrics

Sensitive content requires President or Advisor approval (policy-defined).
