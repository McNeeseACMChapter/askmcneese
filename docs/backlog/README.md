# AskMcNeese — Week 1 Sprint Backlog

**Built by McNeese ACM · Sprint 1 (Foundation) · Week 1 only**

This folder is a **ready-to-forward backlog** for the team. It turns the Week 1
sprint role documents into a single, trackable task list.

---

## Scope of this backlog

This backlog covers **three workstreams**:

- **PM / Full-Stack** (Prince)
- **Content & Knowledge** (source registry)
- **DevOps / QA** (governance and validation)

> **Intentionally excluded:** the **Backend Developer** stream (crawler, cleaner,
> chunker, ChromaDB ingest) and the **Frontend Developer** stream (React + Tailwind
> chat shell). Those two roles already have their own dedicated Week 1 role docs and
> own their tickets separately. They appear here only as **dependencies/handoffs**,
> not as tasks to assign from this board.

## How to use this backlog

1. Import `backlog.csv` into your project board (columns map to: **Backlog → Ready
   → In Progress → Review → Done / Blocked**).
2. Each ticket has an **ID**, **target day**, **acceptance criteria**, and **owner role**.
3. A ticket is only **Done** when its acceptance criteria are met **and** PM has verified it.
4. Keep everything inside Week 1 scope — see the boundaries in `backlog.md`.
