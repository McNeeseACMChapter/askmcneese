# Minimum viable product

First usable release contains **only**:

1. Authentication  
2. Members  
3. Role assignment and approval  
4. Permission enforcement  
5. Meetings and minutes  
6. Decisions and action items  
7. Projects and tasks  
8. Documents  
9. Notifications  
10. Audit trail  

**Do not** include finance in the first release unless authorization and audit have been tested thoroughly.

UI name: **ACM Panel**. Default home: **My Work** (role-aware).
