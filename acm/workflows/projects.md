# Project workflow

```text
IDEA
  → PROPOSAL
  → SCREENING
  → APPROVED
  → PLANNING
  → ACTIVE
  → AT_RISK | BLOCKED
  → REVIEW
  → COMPLETED
  → ARCHIVED
```

## Required project fields

- Problem statement
- Intended users
- Scope / out-of-scope
- Sponsor
- Project Manager
- Technical lead
- Team members
- Milestones
- Acceptance criteria
- Risks / dependencies
- Budget
- Documents / repository links
- Closure report

The Project Manager manages **approved projects**, not the whole chapter.

Self-approval of one’s own proposal is forbidden (Law 3).
Completion requires proof against acceptance criteria (Law 6).
