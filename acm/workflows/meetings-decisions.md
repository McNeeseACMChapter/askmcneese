# Meeting and decision workflow

```text
AGENDA_DRAFT
  → AGENDA_PUBLISHED
  → MEETING_IN_PROGRESS
  → MINUTES_DRAFT
  → MINUTES_REVIEW
  → MINUTES_APPROVED
  → ARCHIVED
```

## Meeting record

A meeting contains:

- Date and location
- Attendees
- Quorum
- Agenda items
- Motions
- Votes
- Decisions
- Action items
- Supporting files

## Structured decisions

A decision must not exist only as prose inside minutes. Promote to a structured record:

```text
Decision: Approve AskMcNeese Phase 2
Owner: Project Manager
Approved by: Executive Board
Date: August 20, 2026
Budget limit: $500
Conditions: Advisor security review required
Related project: AskMcNeese
```

Minutes corrections create a **new version**; prior approved versions remain (Law 4).
