EXECUTIVE SUMMARY
================================================================================

AskMcNeese is a campus information assistant and class planning tool for
McNeese State University students. It is an ACM (Association for Computing
Machinery) student project—NOT an official McNeese State University product.

WHAT IT DOES:
- Answers questions about campus life in plain English
- Searches Fall 2026 class schedules
- Checks schedule conflicts
- Provides cited answers from official sources
- Helps students find information without searching multiple websites

WHAT IT DOESN'T DO:
- Register students for classes
- Access personal student records
- Make decisions for the university
- Replace official university systems
- Guarantee real-time data

WHO IT'S FOR:
- Current and prospective McNeese students
- Anyone seeking campus information
- No login required for basic Ask and Class Planner features

HOW IT WORKS:
- You ask a question in your own words
- The system searches official McNeese sources
- It returns an answer with links to sources
- Class Planner lets you explore courses and check conflicts

TECHNOLOGY:
- Python (FastAPI) backend
- React + TypeScript frontend
- ChromaDB for indexed content
- SQLite/PostgreSQL for class data
- Claude AI for answer generation
- Deployed on Render.com
