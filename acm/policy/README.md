# Phase 0 — Governance specification

**Status:** Draft — decisions required before production implementation.

Formally decide and version the items below. When decided, fill [`decisions.md`](./decisions.md) and bump [`VERSION`](./VERSION).

These decisions become the chapter’s binding configuration for workflows and permissions.

## Must decide

1. Official role names  
2. Appointment authority (who may propose / approve each role)  
3. Election method  
4. Term dates (and whether Fall/Spring vs academic year)  
5. Quorum rules  
6. Voting rules  
7. Officer-removal process  
8. Financial approval thresholds  
9. Advisor approval conditions  
10. Active-member definition  
11. Sensitive communication rules  
12. Data-retention rules
