# Role-specific home screens

Do **not** give every officer the same dashboard with different hidden buttons. Each role gets a primary view of what they are responsible for.

| Role | Primary focus |
|------|----------------|
| Advisor | Access approvals, compliance, high-risk finance, sensitive events, term expiry, incidents, emergency actions |
| President | Objectives, executive commitments, pending decisions, portfolio health, events, budget overview, officer performance |
| Vice President | Overdue officer actions, cross-team blockers, committees needing support, unassigned work, operational readiness |
| Treasurer | Pending finance requests, balances, unreconciled txns, missing receipts, reimbursements, funding deadlines |
| Secretary | Agendas needed, minutes awaiting approval, decisions without actions, membership updates, election evidence |
| Project Manager | Active projects, milestones at risk, blocked tasks, risks, change requests, deliverables awaiting review |
| SGA Representative | SGA meetings, funding deadlines, pending requests, legislation, reports back to ACM |
| Social Media Manager | Content calendar, drafts needing review, event promotion, missing assets, published performance, public messages |
| General Member | Assigned tasks, invitations, meetings, volunteer openings, elections/votes, personal history |

Detail notes: [`homes.md`](./homes.md)
