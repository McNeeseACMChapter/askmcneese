# Home screen checklists by role

## Advisor
- Access approvals pending
- Compliance deadlines
- High-risk financial requests
- Sensitive events
- Officer-term expiration
- Unresolved incidents
- Emergency actions (logged)

## President
- Chapter objectives
- Executive commitments
- Pending decisions
- Project portfolio health
- Upcoming events
- Budget overview
- Officer performance

## Vice President
- Overdue officer actions
- Cross-team blockers
- Committees requiring support
- Unassigned responsibilities
- Operational readiness

## Treasurer
- Pending financial requests
- Budget balances
- Unreconciled transactions
- Missing receipts
- Reimbursements
- Funding deadlines

## Secretary
- Meetings needing agendas
- Minutes waiting for approval
- Decisions not converted into actions
- Membership records needing updates
- Election and appointment evidence

## Project Manager
- Active projects
- Milestones at risk
- Blocked tasks
- Unresolved risks
- Change requests
- Deliverables awaiting review

## SGA Representative
- Upcoming SGA meetings
- Funding deadlines
- Pending requests
- Legislation needing ACM input
- Required reports back to ACM

## Social Media Manager
- Content calendar
- Drafts needing review
- Upcoming event promotion
- Missing assets
- Published performance
- Unanswered public messages

## General Member
- Assigned tasks
- Project invitations
- Upcoming meetings
- Open volunteer opportunities
- Elections and votes
- Personal participation history
