# Event workflow

```text
IDEA
  → FEASIBILITY_REVIEW
  → BUDGET_REVIEW
  → APPROVAL_PENDING
  → APPROVED
  → PROMOTION
  → REGISTRATION_OPEN
  → READY
  → COMPLETED
  → POST_EVENT_REVIEW
  → ARCHIVED
```

## Connections

Every event should connect:

- Event owner
- Advisor requirement (when applicable)
- Facility request
- Budget
- Volunteers
- Speaker
- Registrations / attendance
- Communications
- Safety notes
- Post-event report
